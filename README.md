# Telekinessball

Локальный мультиплеерный футбол на [LÖVE](https://love2d.org/) (Love2D): два игрока на одном экране забивают голы, пиная мячи и управляя ими телекинезом.

## Требования

- [LÖVE 11.x](https://love2d.org/) (или совместимая версия)

## Запуск

Из корня репозитория:

```bash
love .
```

Либо перетащите папку проекта на исполняемый файл LÖVE / откройте её через клиент LÖVE.

## Управление

| Действие | Игрок 1 | Игрок 2 | Геймпад |
| --- | --- | --- | --- |
| Движение | `W` `A` `S` `D` | Стрелки | Левый стик / D-pad |
| Телекинез / бросок | `Space` | `Enter` | Кнопка A |
| Рестарт после матча | `R` | `R` | Кнопка B |
| Полный экран | `F` | | |
| Mute музыки | `M` | | |
| Выход | `Q` / `Esc` | | |

На стартовом экране нажмите **действие** (Space / Enter / A), чтобы начать матч.

## Правила

- На поле три мяча; первый, кто наберёт **5** голов, побеждает.
- Обычный контакт слегка пинает свободный мяч.
- **Действие** в радиусе телекинеза захватывает ближайшие свободные мячи; повторное нажатие запускает их от игрока.
- Игроки не могут заходить в чужую штрафную.
- При простое матч сбрасывается на стартовый экран.

## Структура проекта

```
main.lua          — точка входа LÖVE
config.lua        — игровые константы
input.lua         — привязки клавиатуры / геймпадов
audio.lua         — загрузка BGM и SFX
classes/          — Player, Ball, Goal, Wall, …
states/           — startScreen, gameScreen
libs/             — сторонние библиотеки (bump, anim8, baton, …)
assets/           — спрайты, шрифты, звук
```
